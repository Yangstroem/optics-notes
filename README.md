## 按关键词检索

在仓库根目录使用 Python 3 运行，无需安装额外依赖：

```sh
python3 资料索引/检索.py 费马 --book 1-01 --limit 5
python3 资料索引/检索.py 符号 --book 1-02 --limit 5
python3 资料索引/检索.py 主平面 --book 1-03 --limit 5
```

多个关键词按 AND 匹配；`--book` 限定来源名称，`--limit` 限制展示数量。每条结果标明来源、PDF 文件页码或实际幻灯片页码及文本路径。

## 阅读与解题约定

- 优先遵循相应课件的符号和模型。几何成像计算前，应明确物像虚实、入射方向、距离起算点以及折射率、曲率半径和焦距的符号，尤其核对 1-02 第 35–38 页、1-03 第 10–14 页及第 42 页。
- 引用时区分 PDF 文件页码、教材印刷页码和实际幻灯片页码。王沛、鲁拥华教材正文印刷第 1 页对应 PDF 第 16 页；这一关系不适用于另一本教材。
- 扫描教材的 OCR 适合定位文字，公式、上下标和图中文字需回看原页。PPTX 的矢量光路图、嵌入公式、动画和相对排版以原课件为准，不能由零散文字完整还原。
- 课件中的 P18、P24、P32、P38、P49、P59 等作业标注不能直接套用到另一版本教材。干涉作业解析已有独立的来源核对；其他题目仍应先确认题面与所用版本。
- 文件覆盖的主题不代表已确认的课堂进度；重点标注也不等于考试范围或作业截止日期。
